# Design Review Studio

Use [GENERAL-REVIEW.md](GENERAL-REVIEW.md) for mixed or uncertain media. For a clear category, load just its standalone reviewer:

- [Website](categories/website.md)
- [Product UI](categories/product-ui.md)
- [Poster and Social](categories/poster-and-social.md)
- [Video and Motion](categories/video-and-motion.md)
- [Brand and Logo](categories/brand-and-logo.md)
- [Presentation and Document](categories/presentation-and-document.md)
- [Product and Packaging](categories/product-and-packaging.md)

Select the actual artifact before reviewing. Respect tool limits and established brand decisions. Category reviewers contain the complete workflow and score rules.

Read [evidence and tools](references/evidence-and-tools.md) when selecting inspection tools, and [scoring](references/scoring.md) for calculation details. Use [review report](templates/review-report.md), [builder handoff](templates/builder-handoff.md) and [project brief](templates/project-brief.json) for saved deliverables. Research provenance is in [sources](references/research-sources.md).

Save each review under reviews/<project>/<version>/ with evidence references, report, edit backlog and handoff. Create the directory only for an actual review; preserve inputs. Default to reviewing, not applying changes. No artifact means no score.


Version 1.1.0 incorporates Graphic Design Thinking in every portable reviewer: correctness, composition, consistency, finishing details and final-output verification. These are part of existing categories, not a separate score. Start new users with [the beginner guide](README.md).
