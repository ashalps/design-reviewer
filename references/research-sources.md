# Research and provenance

Reviewed: 2026-11-22. These sources inform original instructions; they are not bundled dependencies, endorsements or evidence that this toolkit has been benchmarked against them. Source product claims were not independently tested.

| Source | Adopted idea | Boundary |
|---|---|---|
| [Humbleteam Design Review](https://github.com/humbleteam/design-review) | Before/After/Why, focused findings, comparison | Do not force issues or treat a score as ship certification |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Reusable project design context, scoped overrides, RTL attention | Preserve the user's brand; do not import a style database or source code |
| [Frame.io review](https://frame.io/features/review-and-approval) | Anchored, time-specific feedback | No Frame.io integration or subscription required |
| [Nielsen Norman Group severity](https://www.nngroup.com/articles/how-to-rate-the-severity-of-usability-problems/) | Impact-based issue severity | Severity differs from effort and aggregate score |
| [Deque axe](https://www.deque.com/axe/devtools/) | Measured accessibility evidence plus manual checks | Automation is not full accessibility verification |
| [Storybook accessibility](https://storybook.js.org/docs/writing-tests/accessibility-testing) | Review component states when already available | Do not install Storybook just to review a screenshot |
| [Lighthouse](https://developer.chrome.com/docs/lighthouse/overview) | Separate performance/accessibility/SEO diagnostics | Lab tests are not field metrics or visual taste ratings |
| [Playwright visual comparisons](https://playwright.dev/docs/test-snapshots) | Stable capture conditions for revisions | Pixel changes are not automatically defects |
| [Google AI features](https://developers.google.com/search/docs/appearance/ai-features) | Existing SEO fundamentals; no special Google AI optimization requirement | No guaranteed citation/ranking or universal special schema |
| [Agent Skills specification](https://agentskills.io/specification) | Portable SKILL.md with focused references | Host discovery and tool access still vary |

## User-provided foundations

- ashal-design-checker: evidence-based critique and preservation of approved direction.
- apple-design: conditional interaction, continuity and accessibility principles.
- animation-vocabulary: precise motion language; no claim that vocabulary alone measures quality.
- seo-geo-aeo: separate discoverability review, adjusted for evidence limits and current authoritative guidance.

The installed originals remain unchanged. No external skill code or full text is copied. Future redistribution of third-party material requires checking its actual license and retaining required notices. Re-verify changing search, platform and technical guidance during applicable reviews; do not assume this research date guarantees current behavior.


## Added in version 1.1.0

- graphic-design-thinking: correctness before aesthetics, composition before decoration, coherent design choices, editable-format preservation and final-export inspection. The installed design philosophy, elevation protocol and interrogation checklist were read. These principles are integrated into all eight portable reviewers; users do not need the original skill or its companion files. The toolkit remains review-only unless editing is requested. No additional score is added for these overlapping principles.
